# AIA ILP Performance Dashboard

Mobile-first advisor dashboard for AIA Singapore ILP funds.

## Architecture
- Mobile PWA frontend
- 41-fund AIA Singapore ILP universe
- S&P 500 Total Return benchmark
- Official fund benchmark field
- Automated GitHub Actions data refresh
- Live/stale data status
- Client Presentation Mode

## Important
Performance values are not populated until a verified data refresh succeeds. No illustrative values are presented as live data.

## Deployment
The `frontend/` directory is intended for GitHub Pages deployment.
